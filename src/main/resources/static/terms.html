Formula 1 API

Termos de Serviço

Última atualização: 3 de novembro de 2026

Estes termos valem para todo uso da Formula 1 API: as chamadas aos endpoints, as chaves de API e a documentação. Ao usar a API, você concorda com eles.

1. O serviço

A Formula 1 API é uma API REST que reúne equipes, chefes de equipe, pilotos, patrocinadores e resultados de corrida, e calcula as tabelas de classificação de pilotos e de construtores a partir desses resultados.

Este é um projeto independente e acadêmico. Ele não tem vínculo com a Formula One Group, a FIA nem as equipes, e os nomes e marcas citados pertencem aos seus donos.

2. Acesso e planos

A leitura dos dados é aberta. Para alterar dados é preciso uma chave de API, enviada no header X-API-Key.

PlanoO que podeLimite
Visitante (sem chave)Ler os dados20 requisições por minuto, por IP
Chave USERLer e alterar os dados100 requisições por minuto, por chave
Chave ADMINTudo isso e gerenciar as chaves1000 requisições por minuto, por chave

Os limites podem mudar. O valor que vale para você vem sempre no header X-Rate-Limit-Limit de cada resposta. Quem passa do limite recebe o status 429 e o header Retry-After, que diz em quantos segundos tentar de novo.

3. Chaves de API

  • A chave é de uso do seu sistema e não deve ser compartilhada nem publicada, por exemplo em código de front-end ou em repositórios públicos.
  • A chave completa aparece uma única vez, quando é criada. Guarde-a em um lugar seguro.
  • Toda alteração feita com a sua chave é de sua responsabilidade.
  • Uma chave pode ser desativada ou revogada a qualquer momento, inclusive em caso de abuso.

4. Uso aceitável

Não é permitido:

  • contornar os limites de requisição, por exemplo trocando de IP ou dividindo chaves para somar cotas;
  • tentar descobrir chaves, explorar falhas ou atrapalhar o funcionamento do serviço;
  • usar a API para fins ilegais ou para enviar conteúdo ofensivo.

5. Dados

  • Os resultados de corrida que vêm com a API são ilustrativos, não são os oficiais.
  • O banco de dados fica em memória: ele volta aos dados iniciais sempre que o serviço reinicia, e o que você cadastrar pode ser perdido a qualquer momento.
  • Não envie dados pessoais ou sensíveis.

6. Disponibilidade

O serviço é oferecido como está, sem garantia de disponibilidade. Na hospedagem gratuita, ele dorme depois de 15 minutos sem uso, e o primeiro acesso depois disso pode levar cerca de 1 minuto.

7. Versões

A versão é escolhida pelo header API-Version. Mudanças que quebram a integração saem em uma versão nova, e a anterior continua no ar por um tempo.

A v1 é a versão padrão e está marcada como obsoleta desde 3 de novembro de 2026, com desligamento previsto para 1º de março de 2027. As respostas da v1 trazem os headers Deprecation e Sunset com essas datas. Recomendamos migrar para a v2.

8. Responsabilidade

A API é usada por sua conta e risco. Não nos responsabilizamos por perdas causadas por indisponibilidade, por dados incorretos ou pelo uso indevido de uma chave.

9. Mudanças nestes termos

Estes termos podem ser atualizados. A data no topo da página indica a versão em vigor, e continuar usando a API depois de uma mudança significa aceitar os novos termos.
